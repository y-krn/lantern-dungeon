# 魔物のバリエーション拡充案（実装仕様）

## 文書の位置づけ

2026-10-17時点の設計提案です。実装はCodexが担当する前提で、仕様・変更箇所・検証条件まで具体的に書いています。数値はすべて初期案で、人による試遊で調整します。

- 基準：`origin/main` `9787a5a`（罠のバリエーション導入後）
- 対象：通常の冒険（灯りの迷宮10階・深淵の迷宮30階）。試作冒険（`?trial=strategy`）でも同じ定義を使います。
- 実装は段階A→B→Cの順に、別々のPRにします。段階Aだけでも遊びが成立します。

## 現状の課題

- 魔物は25種・9系統あります。しかし上位種の多くは、同じ特性のまま数値だけが上がった色違いです（例：洞窟・紅翼・黒曜コウモリはすべて「2歩接近」）。深い階ほど、目新しい判断が生まれにくくなっています。
- この間に、プレイヤー側の手段が大きく増えました。押し出し・引き寄せ、地形（水・油・草・霧・炎）、7種の罠、灯影、矢に灯す、などです。一方で、敵側にはこれらに反応する特性がありません。
- 深淵の11〜30階（出現表の段階3〜6）は6〜7種の使い回しで、20階分の変化が乏しい状態です。

## 設計の原則

1. **新しい特性で増やす**。色違いの能力値違いは増やしません。追加する種はすべて、新しい行動か、新しい弱点を持ちます。
2. **読める脅威**。危険な行動は、既存の射撃・強打と同じく1ターン前に予告するか、図鑑と見た目で事前に分かるようにします。即死や、見えない一撃は作りません。
3. **プレイヤーの手段と噛み合う**。新しい敵ごとに「押し出す・地形・罠・灯影・矢に灯す」のどれかが特に効くようにします。
4. **試遊で却下された方向は使わない**。魔物を灯りや餌で誘う仕組みと、プレイヤーに足踏みや待機を強いる仕組みは入れません。
5. **既存の絵を使う**。新しい種は既存9系統のドット絵を、`colors[1]` による色相回転で塗り分けます（`sprites.js` の `baseSpecies` と同じ仕組み）。新しいドット絵は不要です。

### 特性の詳細ルール

既存の敵ターン（`enemies.js` の `runEnemyTurn`）の流れに沿って記述します。「予告」は既存の `e.intent` を指します。

#### 分裂（split）：泡スライム
- ダメージを受けて生き残り、残りHPが4以上、かつその個体が `split` 済みでない場合に分裂します。残りHPの半分（切り捨て）を持つ分身を、隣接する空きマス（壁・敵・リネ・階段以外）に1体出します。元の個体もHPが半分（切り上げ）になります。
- 元の個体と分身の両方に `split: true` を付け、二度と分裂しないようにします。
- 分身には `spawned: true` を付け、倒した時の経験値を1、金貨を0、灯影の欠片は出さないようにします（増殖による稼ぎ防止）。
- 空きマスがなければ分裂しません。
- 分身の `id` は、その階の敵の最大 `id` + 1 にします（`id` 順の行動順序を保つため）。

#### 腐食（corrode）：錆スライム
- 近接攻撃が当たると、装備中の盾の補正値が1下がります（−3まで）。盾がなければ何も起きません。
- 盾の補正値が判明済みでなくても下げます。その時に `identified = true` にします（錆の罠と同じ扱い）。

#### 泥の跡（mudTrail）：泥スライム
- 移動した後、移動前のマスを水たまりにします。そのマスに地形がない場合だけで、階段のマスは除きます。
- 雷光の灯札と雷の灯の矢で、まとめて感電させる機会になります。逆にリネが水に立つ危険もあります。

#### 盗み（steal）：灯盗みコウモリ
- 近接攻撃が当たった時（ダメージも通常どおり与えます）、リネの持ち物の未装備の道具（文字列の品で、矢を除く）から1つを乱数で盗み、`stolen` に保持します。
- 盗んだ後は逃走状態になります。毎ターン最大2歩、リネとの距離が最も遠くなる方向へ移動し、攻撃しません。
- 倒すと、盗んだ品をその場（または隣の空きマス）に落とします。
- 階を移ると、盗まれた品は失われます。
- 盗める品がなければ、通常の近接攻撃だけになります。

#### 呼び声（call）：鐘鳴りコウモリ
- 初めて目を覚ましたターン（`awake` が false から true になった時）に、同じ部屋と半径3マス以内の魔物をすべて起こします。
- 起こすだけで、魔物をどこかへ集める効果はありません。
- 図鑑に「目を覚ますと仲間を起こす」と明記します。

#### 突進（charge）：角甲虫
- 予告：起きていて、リネが8方向の直線上の4マス以内にいて、途中に壁・閉じた角・他の魔物がない時に、突進を予告します。予告は `intent = { kind: "charge", x, y, dx, dy, length }` で、`(x, y)` は予告時のリネの位置です。
  - 描画では、角甲虫の隣から `length` マス分の直線すべてを危険マスとして表示します。
- 実行（次の敵ターン）：予告した方向へ最大 `length + 1` マス、1マスずつ進みます。
  - リネに当たった場合：攻撃力×1.5（切り上げ）のダメージを与え、リネを同じ方向へ1マス押し出します（押し出し先が空いている時だけ。着地で罠が発動します）。角甲虫はリネの手前で止まります。
  - 壁に当たった場合：角甲虫が6ダメージを受け、次の1回の行動を失います（`stunned: true`。次のターンに消費します）。
  - 他の魔物に当たった場合：両者が8ダメージを受けて止まります。
  - 罠・地形：通ったマスの罠は発動します（`landing()`）。炎のマスも避けません（突進中は止まれない）。
- リネが予告の直線から外れていれば空振りになり、角甲虫は直線の端まで進みます。

#### 反射（mirror）：鏡甲虫
- 矢（`kind: "arrow"`）と灯弾（`lanternShot`）のダメージは鏡甲虫に入らず、リネが同じダメージの半分（切り上げ）を受けます。ログに「矢が跳ね返った」と表示します。
- 雷の灯の矢の追加効果（伝導・追加6ダメージ）も発生しません。
- 近接攻撃、押し出しの衝突、罠、炎、爆発、雷光の灯札（`magic`）は通常どおり効きます。

#### 足止め射撃（snare）：絡み蔦
- 棘吐き草と同じく移動せず、直線3マス以内を予告して射撃します。
- 当たると、リネは次の1ターン移動できなくなります（`player.bindUntil = turn + 1`）。攻撃・道具の使用は可能です。
  - 拘束の処理は現在、試作冒険の `strategy.js` にしかありません。`engine.js` の `move()` に「拘束中は移動不可（攻撃は可）」を追加し、試作と同じ挙動にします。
  - 試作冒険の蔓の拘束（`bindUntil`・`resistUntil`）と同じフィールドを使い、二重に実装しないようにします。
- 草むら・霧の中のリネは狙われません（既存の `concealed()` に従います）。

#### 爆散（burst）：爆ぜ蛾
- 倒れた時に周囲3×3が爆発し、範囲内のリネと魔物に10ダメージを与えます。油・草むらには火が付きます。
- 爆発で倒れた別の爆ぜ蛾も爆発します（連鎖）。連鎖は1回の処理の中で、再帰ではなくキューで処理してください。
- 爆発で倒した魔物の経験値・金貨・灯影の欠片は、通常どおりリネに入ります。
- 見た目：HPが半分以下の時、体が明るく点滅します（描画のみ）。

#### 間合い（kite）：影弓の亡霊
- 射撃（射程4、予告あり）を持つ亡霊です。
- 敵ターンの開始時にリネと隣接していて、リネとの距離が2以上になる空きマスへ1歩動ける場合は、射撃の予告をせずに下がります。
- 下がれない時（壁際・通路の行き止まり）は、通常の近接攻撃をします。
- 曲がり角に追い込むか、鉤の鎌で引き寄せて殴ることを想定しています。

#### 癒し（mend）：癒し灯の亡霊
- 自分の行動の代わりに、半径3マス以内で最もHPの割合が低い他の魔物（最大HP未満のもの）を8回復します。対象がいなければ通常どおり行動します。
- リネと隣接していれば、間合いと同じ規則で下がります。
- 回復は見えている時だけログと演出を出します。

#### 正面の守り（ward）：大盾ゴーレム
- リネの近接攻撃・矢・灯弾によるダメージを半分（切り上げ）にします。
- 押し出しの衝突、罠、炎、爆発、雷光の灯札（`magic`）は軽減しません。
- 移動は2ターンに1歩（既存ゴーレムと同じ `cadence: 2`）で、強打の予告はしません（通常の近接攻撃）。
- 罠・地形・押し出しで倒すことを促す敵です。

### 出現表

`MONSTER_POOLS` の各段階に、次のように追加します。段階0は苔スライムのみのまま変えません（チュートリアルの導入を保つため）。

- 段階1：`bubbleSlime`
- 段階2：`thiefBat`、`snareVine`
- 段階3：`rustSlime`、`bellBat`、`hornBeetle`、`blastMoth`
- 段階4：`mudSlime`、`archerGhost`、`wardGolem`
- 段階5：`mirrorBeetle`、`mendGhost`
- 段階6：段階4・5の新種から `archerGhost`、`mirrorBeetle`、`wardGolem` も入れる

色違いの既存種が多い段階（4〜6）の比率が下がり、深い階ほど行動の違う敵と出会うようになります。

## 段階B：灯冠の魔物（精鋭）

Diablo・Hadesの精鋭のように、既存の魔物を変化させてバリエーションを増やします。

- 出現：実際の深さ（深淵は+2）が5以上の階で、通常の魔物（モンスターハウスと番人を除く）の6%を「灯冠」にします。
- 能力：HP×1.5（切り上げ）、攻撃力×1.2（切り上げ）、経験値×2。名前の前に「灯冠の」を付けます。
- 報酬：倒すと灯影の欠片を必ず残します（救済の回数は消費しません）。
- 見た目：頭上に金色の小さな冠を描きます（色だけに頼らず、形で示すため）。
- 保存：敵に `elite: true` を付けます。`save.js` の「maxHp・attack・exp が種の値と一致すること」の検証を、`elite` の場合は灯冠の値と照合するように変えます。

## 段階C：深淵の中ボス（任意）

深淵の10階・20階に、番人以外の中ボスを1体置く案です。段階A・Bの試遊結果を見てから判断します。

- 10階「大泡の母体」：分裂を3回まで繰り返す大型の泡スライム（HP120）。
- 20階「鉄門の大ゴーレム」：正面の守りと突進を持つ（HP200）。

中ボスを倒すと階段が開く形にはせず、倒すと灯台の候補が1つ増える、などの報酬にします。

### 守るべき既存の約束

- 敵の行動順は `id` の昇順です。新しく生まれた分身も、この順序に従います。
- 予告した攻撃は、予告した次の敵ターンにだけ実行します。予告マスをリネの移動に合わせて付け替えません（既存の射撃・強打と同じ）。
- 見えていない敵の行動では、ログと演出を出しません（試作冒険の `strike()` と同じ方針）。
- 未発見の情報は、対象候補・ログ・自動プレイの観測に漏らしません。たとえば盗んだ品の種類は、そのコウモリが見えている時だけログに出します。
- 旧セーブ（新フィールドなし）は、そのまま再開できるようにします。

## 検証

### 単体の検証（`node check.cjs` に追加）

- 12種すべてが `MONSTERS`・`ECHO_SOURCES`・出現表のいずれかの段階に入っていること。番人以外のすべての種が灯影に対応していること（既存の検証）。
- 分裂：残りHPの条件、1回だけ、空きマスがない時、分身の経験値と灯影なし、`id` の順序。
- 腐食：盾の補正値−1、−3で止まる、盾なし。
- 泥の跡：移動元のマスが水になる、階段と既存の地形は上書きしない。
- 盗み：盗む品の条件（矢と装備は対象外）、逃走中は攻撃しない、倒すと落とす、階移動で失う。
- 呼び声：起きた時の1回だけ、範囲内だけ。
- 突進：予告の条件（直線・射程・遮断）、命中時のダメージと押し出し（罠の発動を含む）、壁での気絶と次の行動の消費、魔物との衝突、空振り、保存・再読込での予告の維持。
- 反射：矢・灯弾が跳ね返る、近接・衝突・`magic` は通る、雷の灯の追加効果が出ない。
- 足止め射撃：命中後の1ターン移動不可、攻撃と道具は可能、草むら・霧では狙われない。
- 爆散：3×3の範囲、リネも対象、油・草への着火、連鎖、報酬の付与。
- 間合い：隣接時に下がる、下がれない時の近接攻撃。
- 癒し：最も割合の低い魔物を回復、対象なしでは通常行動。
- 正面の守り：近接・矢・灯弾が半減、`magic` は全量。
- 灯冠（段階B）：出現条件、能力補正、欠片の確定、保存の検証。

- 通常の自動プレイ（例：シード101〜103、600ターン）と深淵の自動プレイで、ブラウザ例外・入力停滞・保存復帰の不一致がないこと。
- 390×844・320×568で、突進予告の直線、爆ぜ蛾の点滅、灯冠の冠が他の表示と重ならず読めること。

### 試遊で確かめること

- 新しい敵ごとに、出会った時の対処が既存の敵と変わったか（押し出す、地形を使う、罠に誘導する、優先して倒す、など）。
- 突進・反射・正面の守りが「理不尽」と感じられないか。予告と図鑑の説明で理由が分かるか。
- 盗みと腐食が不快すぎないか。不快なら、段階Aから外すか数値を下げます。

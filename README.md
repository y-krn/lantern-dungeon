# 灯りの迷宮 — 小さな商人の大冒険

「トルネコの大冒険」のような、一歩ごとに世界が動くブラウザ用ローグライク。キャラクター、名称、ドット絵、効果音は独自のものです。キャラクターは正面・横・背面・斜めを含む8方向のドット絵と方向マーカーで向きを表示します。ライブラリやビルド工程を必要としません。

## 起動

このディレクトリで実行し、`http://localhost:4173` を開きます。

```sh
python3 -m http.server 4173 --directory dist
```

`dist/index.html` を直接開くこともできます。保存の利用可否はブラウザの設定によります。保存できない場合は画面に表示されます。

## 操作と目的

- 矢印キー / WASD：移動。敵へ移動すると攻撃。
- Q / E / Z / C：左上 / 右上 / 左下 / 右下への移動。
- Shift＋移動キー：その場で向きだけ変更。8方向に対応し、ターン・満腹度は変わらず、敵も動きません。
- T / 「向き変更」ボタン：向き変更モードの切替。方向ボタン・移動キー・迷宮タップが向き変更になります。もう一度押すと移動に戻ります。
- Space / F：向いている方向へ攻撃。
- R：装備した木の矢を向いている方向へ発射。1本消費し、最初の敵に12ダメージ。
- . / X：足踏み。
- I：持ち物。アイテムの使用・装備・装備解除で1ターン進みます。木の矢は「装備」で剣・盾と併用でき、「外す」で解除できます。矢は「木の矢 × 本数」とまとめて表示し、本数にかかわらず持ち物の1枠を使います。
- Enter：階段の上で次の階へ。
- M：ミニマップ切替。H / ?：遊び方。
- スマートフォン：迷宮直下の方向ボタン。迷宮をタップしても、その方向へ1歩移動できます。

最初はチュートリアル「灯りの迷宮」（10階）を探索します。地下10階の星の番人を倒し、星のランタンへ到達するとチュートリアル完了です。クリア後に「深淵の迷宮」（30階）が解放され、クリア画面または「ダンジョン選択」から挑戦できます。地下30階の深淵の番人を倒し、深淵のランタンへ到達するとクリアです。

深淵の迷宮は敵が各階2体増加し、通常敵の出現表を2階先へ進めます。同じ名前の敵に追加の能力補正はかかりません。罠は各階最大8個、パンは各階2個です（チュートリアルは最大5個、パン3個）。剣は2・5・8階以降3階ごと、盾は3階ごとに出現し、深層でも装備を強化できます。冒険ごとにレベル・持ち物・所持金は初期化されます。体力が0になると冒険が終了します。

迷宮は6部屋を接続して毎階生成します。視界、敵の追跡、経験値とレベル、剣と盾、罠、回復草、パン、矢、雷の巻物、地図の巻物を実装しています。満腹度は4ターンで1減少し、0になると毎ターン体力が減ります。満腹時は7ターンごとに体力が1回復します。

ブラウザの `localStorage` に行動ごとに保存します。端末・ブラウザ・URLごとに独立した保存です。チュートリアルのクリアによる解放は冒険セーブと別に保存され、死亡・再挑戦後も維持されます。従来のセーブはチュートリアルとして復帰し、保存済みクリアは解放を引き継ぎます。ブラウザの保存データを消すと解放状態も消えます。サーバー保存や端末間同期はありません。Google Fonts の取得に失敗した場合はシステムフォントを使用します。

## 魔物のバリエーション

魔物は全15種です。同じ名前ならHP・攻撃力・経験値は固定で、階数やダンジョンによる能力補正はありません。強い別種は名前と体色、頭の模様で見分けられます。「遊び方」から「魔物図鑑を見る」を開くと、ドット絵と能力を確認できます。氷・雷などの名称は外見のテーマで、現在は全種が通常の移動と近接攻撃を行います。

通常敵の出現表は以下のとおりです。深淵の迷宮では実際の階数に2を加えて参照します。チュートリアルは10階で終わります。

- 1〜2階相当：苔スライム（苔色、無印）。
- 3〜5階相当：琥珀スライム（琥珀色、横線）、洞窟コウモリ（紫、横線）。
- 6〜10階相当：紅翼コウモリ（赤、菱形）、灯りの亡霊（薄桃色、菱形）。
- 11〜15階相当：氷翼コウモリ、氷灯の亡霊（水色、山形）。
- 16〜20階相当：雷翼コウモリ（黄）、黄金の亡霊（金色）。頭の模様は十字です。
- 21〜25階相当：翡翠コウモリ、翡翠の亡霊（翡翠色、王冠）。
- 26階相当以降：黒曜コウモリ（銀灰色）、深淵の亡霊（銀紫色）。頭の模様は星形です。
- ボス：星の番人（金色、十字、チュートリアル10階）、深淵の番人（青紫色、星形、深淵30階）。

従来のセーブにいる敵も対応する別種へ移行します。受けたダメージ、位置、追跡状態、モンスターハウスの状態を引き継ぎ、倒した敵は復活しません。瀕死の敵はHP 1を下限として引き継ぎます。

## 検証

```sh
node --check dist/engine.js
node --check dist/game.js
node check-engine.cjs
```

`check-engine.cjs` は全15種の出現、4,000階での同名敵の能力固定、ダメージを受けた旧セーブの移行と再保存も検証します。100シード×チュートリアル10階と100シード×深淵30階の接続、階段到達、アイテム・敵・罠の配置、満腹度、アイテム消費、矢の装備・解除・スタック・残数・持ち物の容量、レベルアップ、旧セーブを含むセーブ復帰、死亡、番人によるクリア条件、30階の終端、チュートリアル完了後の解放、冒険切替・再読込・保存失敗時の解放維持を検証します。

## ファイル

- `dist/index.html`：画面と操作パネル。
- `dist/style.css`：デスクトップ・タッチ端末の表示。
- `dist/engine.js`：シード付き乱数、迷宮生成、ターン制ルール。
- `dist/game.js`：Canvas描画、ドット絵、操作、効果音、自動保存。
- `.openai/hosting.json`：Sitesの配置先と静的配信設定。

ゲーム中の読み取り専用スナップショットは `window.lanternGame.snapshot()` から取得できます。
